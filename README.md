## Tentang Repositori Ini

Repositori ini digunakan sebagai halaman utama **botjev.github.io** sekaligus ruang kolaborasi pengembangan proyek, dokumentasi, dan aset digital.

## Fokus Pengembangan

* **Web & GitHub Pages** — Pengelolaan halaman statis, struktur dokumentasi, dan tampilan antarmuka yang ringan.
* **Aset Visual (SVG)** — Penyimpanan dan eksperimen ilustrasi vektor yang tajam di berbagai ukuran layar.
* **Eksperimen & Otomatisasi** — Ruang uji coba alur kerja kolaborasi berbasis Git, Pull Request, dan dokumentasi terbuka.

## Kolaborasi

* Struktur & dokumentasi disusun bersama [@gadun](https://github.com/gadun).
* Kontribusi perbaikan dokumentasi dan aset visual dilakukan melalui alur *Fork & Pull Request* agar setiap perubahan tercatat rapi.
